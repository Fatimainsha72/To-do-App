# ✅ To-Do List App

A simple and intuitive To-Do List application to help users manage their daily tasks. Built using HTML, CSS, and JavaScript, it allows users to add, mark, and delete tasks easily.

## ✨ Features

- 📝 Add new tasks
- ✔️ Mark tasks as completed
- ❌ Delete tasks
- 💾 Tasks persist with local storage
- 📱 Responsive and user-friendly interface
  
## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
